# JSON парсер без использования сторонних библиотек

Библиотека для парсинга JSON строк в объекты Java и обратной сериализации. Поддерживает работу с Map, коллекциями, массивами и пользовательскими классами без использования внешних зависимостей.

## Сборка и запуск

1. Откройте терминал или командную строку и перейдите в корневую директорию проекта, где находится файл Main.java и папка jsonengine.

2. Скомпилируйте библиотеку и демонстрационный класс с помощью javac:

    Для Windows (cmd):
    ```
    javac jsonengine\*.java Main.java
    ```
    Для Linux / macOS / PowerShell:
    ```
    javac jsonengine/*.java Main.java
    ```

3. Запуск
    ```
    java Main
    ```
