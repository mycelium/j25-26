# Load testing report

## Настройка и запуск

### Требования
- Java 21+ (для поддержки виртуальных потоков)
- Gradle
- Библиотека gson версии 2.10.1

### Сборка и запуск

1. Открыть проект в корневой папке `3`.

2. Запуск нагрузочного тестирования:
```bash
.\gradlew run
```

---

## Описание эксперимента

В работе проводится сравнение производительности HTTP-сервера и JSON-парсеров при различных конфигурациях многопоточности.

Сравниваются следующие конфигурации:
1. Виртуальные потоки + парсер из lab-1
2. Виртуальные потоки + Gson
3. Классические потоки + парсер из lab-1
4. Классические потоки + Gson

Для каждой конфигурации измеряется среднее время обработки двух типов запросов:

### Request-1
Сервер:
- принимает JSON запрос;
- выполняет парсинг JSON;
- сохраняет данные в файл;
- считывает данные из файла;
- возвращает HTTP ответ.

### Request-2
Сервер:
- принимает JSON запрос;
- выполняет парсинг JSON;
- выполняет вычисления в памяти;
- формирует JSON ответ.

## Вывод

В ходе тестирования все конфигурации успешно обработали запросы.

Полученные результаты показывают, что:
- собственный JSON-парсер демонстрирует производительность, сопоставимую с Gson;
- классические потоки в данном эксперименте показали меньшее среднее время обработки запросов;
- виртуальные потоки также обеспечивают стабильную производительность и корректную многопоточную обработку запросов.

Разработанное решение поддерживает:
- многопоточную обработку HTTP-запросов;
- сериализацию и десериализацию JSON;
- конфигурируемый тип ExecutorService;
- нагрузочное тестирование различных конфигураций сервера.
