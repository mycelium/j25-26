# Load Testing 

## 1. How to configure and launch

1. Переход в корень проекта:
```bash
cd tasks\term-2\3
```

2. Компиляция:
```bash
javac -d out -cp "lib/*" src/main/java/com/loadtest/*.java
```

3. Запустить **все 8 экспериментов** (Windows; на Unix разделитель classpath `:` вместо `;`):
```bash
java -cp "lib/*;out" com.loadtest.RunTests
```
В конце будет выведена итоговая таблица.

---

## 2. Описание эксперимента

Сервер обслуживает два endpoint'а:

- **POST `/file`** (Request-1) — парсит JSON, пишет поле `data` в файл `./storage/<uuid>.txt`, читает его обратно, возвращает JSON-ответ. **I/O-bound**.
- **POST `/compute`** (Request-2) — парсит JSON, считает count / sum / mean массива `numbers`, возвращает JSON. **CPU-bound**, без I/O.

Для каждой из 4 конфигураций сервера × 2 endpoint'а = **8 ячеек** клиент:
1. Делает 200 запросов.
2. Шлёт `requests` запросов в `concurrency` потоков.
3. Считает среднее время на запрос в мс — это значение и попадает в таблицу.

Между конфигурациями сервер перезапускается.

## 4. Параметры эксперимента

| Параметр                        | Значение                                                            |
|---------------------------------|---------------------------------------------------------------------|
| Запросов на ячейку              | **2 000**                                                           |
| Concurrency клиента (потоков)   | **50**                                                              |
| Прогревочных запросов           | 200                                                         |
| Размер classic-потоков (сервер) | 50                                                                  |
| Порт сервера                    | выделяется ОС на каждую итерацию                         |
| Тело `/file`                          | `{"data":"hello world from the load testing client"}` (~50 байт)    |
| Тело `/compute`                       | `{"numbers":[1,2,…,50]}` (50 чисел, ~150 байт)                      |
| Версия Gson                     | 2.10.1                                                              |
