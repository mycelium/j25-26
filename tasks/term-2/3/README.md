# Load testing report
## 1. Конфигурация и запуск

### Зависимости
- JAR файлы в `lib/`: `gson-2.10.1.jar`, `httpserver.jar`, `jsonparser.jar`

### Запуск
В `ServerApp.java` выставить флаги:
   - `USE_VIRTUAL_THREADS` (true=Virtual, false=Platform)
   - `USE_GSON` (true=Gson, false=Own parser)
Компиляция:
```bash
   javac -cp "lib/*" src/ServerApp.java src/LoadTest.java
```
Запуск сервера:
```bash
   java -cp "lib/*;src" ServerApp
```
Запуск теста (в другом терминале):
```bash
   java -cp "lib/*;src" LoadTest
```
Повторить для всех 4 конфигураций, меняя флаги в ServerApp.java

## 2. Описание эксперимента

Сравнение производительности HTTP-сервера в 4 конфигурациях:
   - Виртуальные потоки, собственный парсер JSON
   - Виртуальные потоки, Gson 
   - Обычный пул потоков, собственный парсер JSON
   - Обычный пул потоков, Gson
Два типа запросов:
- Request-1 (I/O bound): парсинг JSON → запись в файл storage.txt → чтение из файла → ответ
- Request-2 (CPU bound): парсинг JSON → сложение чисел в памяти → ответ


## 3. Аппаратное обеспечение
- Операционная Система: Windows 11 
- Процессор: Intel Core i5 13500H
- Оперативная память: 16 ГБ
