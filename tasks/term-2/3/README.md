# Нагрузочное тестирование

## 1. Настройка

### Требования 
- Java 21+
- gson-2.11.0.jar
- httpServer.jar
- jsonParser.jar

### Компиляция файлов

javac -d build -cp "lib/*" src/Main.java src/Tests.java

### Запуск сервера
java -cp "build;lib/*" Main

### Запуск тестов
java -cp "build;lib/*" Tests

## 2. Описание тестов

Проводится сравнение производительности сервера в 4 вариантах:

| № | Потоки | Парсер |
|:---|:---|:---|
| 1 | Virtual Threads | Свой |
| 2 | Virtual Threads | Gson |
| 3 | Classic Thread Pool | Свой |
| 4 | Classic Thread Pool | Gson |

Также реализовано 2 варианта запросов.
В первом варианте после парсинга JSON происходит запись в файл. Далее получение данных происходит из файла (.txt).
Во втором варинте данные берутся сразу из памяти.
