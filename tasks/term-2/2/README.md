# HTTP сервер

Библиотека для парсинга JSON строк в объекты Java и обратной сериализации. Поддерживает работу с Map, коллекциями, массивами и пользовательскими классами без использования внешних зависимостей.

## Сборка и запуск

1. Откройте терминал или командную строку и перейдите в корневую директорию проекта, где находится файл Main.java и папка http.

2. Скомпилируйте исходные файлы:

    Для Windows (cmd):
    ```
    javac http\*.java Main.java
    ```
    Для Linux / macOS / PowerShell:
    ```
    javac http/*.java Main.java
    ```

3. Запуск
    ```
    java Main
    ```

4. Сервер будет запущен на 127.0.0.1:12345
