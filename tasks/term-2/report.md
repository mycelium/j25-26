# 2
Цель данной работы - оценить производительность созданного HTTP-сервера из абораторной работы №2 
сравнив его с промышленными решениями.
Сценарии работы:
1)  Работа с файлом:
- Принимает POST-запрос в формате JSON.
- Парсит JSON.
- Записывает данные в локальный файл (test_data.json).
- Считывает данные обратно из файла.
- Возвращает полученный JSON.
2) Работа с памятью:
- Принимает POST-запрос в формате JSON.
- Парсит JSON и сохраняет объект в HashMap.
- Извлекает объект по сгенерированному ID.
- Конвертирует его обратно в JSON и возвращает.
